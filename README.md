# Python Freelance Portfolio

Проекты по парсингу данных и автоматизации, созданные для фриланс-заказов.

## Навыки
- Python 3.x
- BeautifulSoup4, Requests
- Pandas (обработка и экспорт в Excel)
- Работа с HTML, CSS-селекторами
- Сохранение данных в Excel/CSV

## Проекты

### 1. Парсер книжного магазина (books.toscrape.com)
Скрипт собирает названия, цены и ссылки на изображения книг и сохраняет в Excel.
Файл: `portal.py`

### 2. Парсер цитат (quotes.toscrape.com)
Сбор цитат и авторов с последующей записью в Excel.
Файл: `new.py`
